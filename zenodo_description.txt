Custom scripts, Jupyter notebooks and processed data generated during the analyses for manuscript "Novel examples of NMD escape through alternative intronic polyadenylation".

The notebooks document the main analysis workflow in this archive. Candidate-event lists are generated first, then GTEx tissue-level junction support and surrounding-exon coverage are summarized, these summarized data are used for figure generation and final output tables.

Contents:

 - R notebooks used to generate lists of candidate events - poison exons followed by a PAS (`ATE-PE_from_PAS(IorII).ipynb` for cases I and II, `ATE-PE_from_novel_junc(III).ipynb` for case III)
 - Bash scripts that collect preprocessed GTEx coverage and junction data (`ATEPE_from_PAS_data/` and `ATEPE_from_novel_junc_data/`)
 - R notebooks that summarize GTEx tissue-level junction support and coverage (`tissue_data_PAS(IorII).ipynb` and `tissue_data_novel_junc(III).ipynb`)
 - R notebook that assembles manuscript diagrams and figure panels from summarized data: `diagrams_fig2,3,4.ipynb`
 - Data table with 50 events that undergo tissue-specific isoform switch: `tissue_specific_hits.allcases.dtau025_qval01.n50.csv` (raw table for manuscript Table 1)
 - Supplementary Data File 1 - 451 candidate events of NMD escape via intronic polyadenylation (`DataTable1.csv`)
   - Columns include gene name, poison exon coordinates, exclusion junction coordinates, case (I, II or III), stop codon coordinates; metrics calculated from GTEx data: tau range, min(tau), psi1 range, cor(psi1, tau), p-value of the correlation test, adjusted p-value (qval); PAS coordinates and PAS source - TE (annotated), pAread or PolyASite; for case I and II: pAread support and PAS usage in polyASite; for case III: total split read support of I2 junction in GTEx.
   - The file contains 474 rows because some candidate events are represented by more than one entry.
 - RData files generated by the notebooks, including intermediate GTEx-derived data and preprocessed NMD inhibition data.
 - `README.md` with a detailed description of the archive contents, short analysis workflow and required packages.
