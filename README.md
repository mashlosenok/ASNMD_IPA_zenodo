This folder contains custom scripts, Jupyter notebooks, and processed data generated during the analyses for the manuscript "Novel examples of NMD escape through alternative intronic polyadenylation".

The purpose of this archive is transparency of the performed data analysis.

## Contents

### Top-level files

- `ATE-PE_from_PAS(IorII).ipynb` and `ATE-PE_from_novel_junc(III).ipynb`
  - R notebooks used to generate lists of candidate events - poison exons followed by a PAS.
  - For cases I and II (i.e annotated poison exons with a downstream PAS) - `ATE-PE_from_PAS(IorII).ipynb`, for case III (i.e annotated alternative terminal exons linked to the downstream part of the gene by a splice junction from GTEx data) - `ATE-PE_from_novel_junc(III).ipynb`.
  - Role in the archive: analysis notebook.
  - Output type: lists of candidate events with genomic coordinates of corresponding splice junctions and surrounding constitutive exons, used in downstream analysis.

- `tissue_data_PAS(IorII).ipynb` and `tissue_data_novel_junc(III).ipynb`
  - R notebook that summarizes GTEx tissue-level split read support of splice junctions and read coverage of constitutive exons surrounding the poison exons.
  - `tissue_data_PAS(IorII).ipynb` - for case I and II events, `tissue_data_novel_junc(III).ipynb`  - case III events.
  - Role in the archive: intermediate analysis notebook.
  - Output type: intermediate summarized data for manuscript tables/figures.

- `diagrams_fig2,3,4.ipynb`
  - R notebook used to assemble manuscript diagrams and figure panels from the summarized data generated by previous notebooks.
  - Role in the archive: figure-generation notebook.
  - Output type: final figure-ready analysis objects and plots used in manuscript figures, final output tables.

- `DataTable1.csv`
  - Supplementary Data File 1.
  - Contains the 451 candidate events of NMD escape via intronic polyadenylation reported in the manuscript.
  - Role in the archive: final output table.

- `tissue_specific_hits.allcases.dtau025_qval01.n50.csv`
  - Table of 50 events that undergo tissue-specific isoform switch.
  - Corresponds to the raw table underlying Table 1 in the manuscript.
  - Role in the archive: final output table.

- `README.md`
  - Description of the archive contents, workflow, and software context.

## Analysis Workflow

The notebooks represent the main documented analysis flow in this archive.

1. Generation of list of poison exons followed by a PAS
   - `ATE-PE_from_PAS(IorII).ipynb`
   - `ATE-PE_from_novel_junc(III).ipynb`
   - Inputs: external annotation/reference resources and GTEx-derived splice junctions list.
   - Outputs: candidate-event tables used in downstream analyses. In this archive, the generated tables are retained in `ATEPE_from_PAS_data/` and `ATEPE_from_novel_junc_data/`.

2. Tissue-level data summarization
   - `tissue_data_PAS(IorII).ipynb`
   - `tissue_data_novel_junc(III).ipynb`
   - Inputs: candidate-event tables and preprocessed per-sample data from GTEx: junction counts and read coverage of constitutive exons surrounding the poison exons.
   - Outputs: summarized tissue-level metrics, intermediate objects used later for figures and Supplementary Data File 1 (`DataTable1.csv`). In this archive, the generated intermediate data files are retained in `ATEPE_from_PAS_data/` and `ATEPE_from_novel_junc_data/`.

3. Figure generation 
   - `diagrams_fig2,3,4.ipynb`
   - Inputs: summarized outputs from the tissue-level notebooks (`.RData` files from `ATEPE_from_PAS_data/` and `ATEPE_from_novel_junc_data/`) and preprocessed files from NMD inhibition analysis stored in `CHX_data/`.
   - Outputs: figure-ready plots/objects corresponding to manuscript figures, table of events with tissue-specific isoform switch (`tissue_specific_hits.allcases.dtau025_qval01.n50.csv`).

These external resources are not packaged here as a self-contained rerunnable pipeline.

## Final Tables

### `DataTable1.csv`

Supplementary Data File 1 containing candidate events of NMD escape via intronic polyadenylation.

Included columns describe:

- gene name
- poison exon coordinates
- exclusion junction coordinates
- case assignment (I, II, or III)
- stop-codon coordinates
- GTEx-derived summary metrics: tau range, minimum tau, psi1 range, value of Spearman correlation between psi1 and tau, correlation statistics (p-value and adjusted p-value)
- PAS coordinates and PAS source (TE (annotated), pAread or PolyASite)
- for case I and II: pAread support, PAS usage (tpm) reported in polyASite database; 
- for case III: total split read support of I2 junction in GTEx.

Note: the file contains 474 rows although it summarizes 451 candidate events, because some events are represented by multiple entries arising from transcript structure or annotation relationships. Specifically, some poison exons are within exclusion junctions that have a TASS, some poison exons lie within more than one exclusion junction, some poison exons have more than one stop codon, some poison exons are within a region attributed to more than one genes. 

### `tissue_specific_hits.allcases.dtau025_qval01.n50.csv`

Data table with 50 events that undergo tissue-specific isoform switch; this is the raw table underlying manuscript Table 1.
